# Syntra - Personal Digital Twin

An intelligent life operating system for predictive health and financial insights. Built for the Texas Instruments Hackathon (Theme 2).

## The Architecture
- **Frontend:** Next.js, Tailwind CSS, Recharts
- **Backend:** Next.js API Routes
- **Database:** MongoDB Atlas
- **Intelligence:** Gemini API (For explainable insights, not calculations)

## Local Setup (For the Team)
1. Clone this repository: `git clone https://github.com/Aether-Syndicate/syntra.git`
2. Install dependencies: `npm install`
3. Duplicate `.env.example`, rename it to `.env`, and add your local keys.
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
