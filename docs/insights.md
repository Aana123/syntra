# Syntra — Insights

The Insights page surfaces deep per-domain analysis and the cross-domain reasoning that makes Syntra a twin system rather than three separate trackers.

---

## Daily Reflection

The daily reflection is the AI's primary narrative — a 2–4 sentence personalized summary of the user's current trajectory, generated by Gemini 2.5 Flash from the last 42 logs.

### Source
`GET /api/ai/recommend` → `ai.dailyReflection` (string)

### Generation logic
1. `buildTwinContext(logs)` computes weekly averages, trends, and behavioral flags
2. The reflection prompt instructs Gemini to address: what's going well, what's declining, and one prediction
3. The reflection is stored in `user.aiSnapshot.dailyReflection` (cached as a MongoDB Object)
4. Cache is valid for the same calendar day unless a newer log exists

### Twin prediction
`ai.twinPrediction` — a forward-looking statement about the next 3–7 days based on current trajectory. Distinct from `dailyReflection` in that it describes what *will* happen, not what *has* happened.

### Explainability
`ai.explainability[]` — 3–5 plain-language sentences explaining each domain score:
```
"Sleep hours averaging 6.2h this week — health score pulled down by 12 points"
"Discretionary spending 23% over budget — finance score recovery stalled"
"4+ daily study hours for 5 consecutive days — career score accelerating"
```

## Recommendations

### Daily recommendations
Three domain-specific recommendation lists from `ai.recommendations.{health|finance|career}[]`.

Each recommendation is:
- **Actionable** — specific, doable today
- **Context-aware** — generated from the user's actual data patterns, not generic advice
- **Calibrated** — assertiveness scales with confidence (more data = more specific recommendations)

### Daily challenge
`ai.dailyChallenge` — a single focused action tied to the user's weakest domain:
```typescript
{
  title: string;       // Short action title
  description: string; // What to do and why
  domain: "health" | "finance" | "career";
  xpReward: number;    // XP for completing it
}
```

The challenge difficulty and XP reward are calibrated to the current domain score — lower scores yield easier, higher-reward challenges to drive recovery.

### Risk alerts
`ai.riskAlerts[]` — 0 to 3 proactive warnings. Only generated when drift or behavioral patterns indicate risk:
```
"Sleep <6h for 2 consecutive nights — decision-making quality likely impaired"
"Discretionary spend spiking on high-stress days — stress-spending pattern detected"
"Study consistency dropped 40% this week — career trajectory may plateau"
```

## Domain-Specific Analysis

Accessed from the Insights page tab selection. Each domain triggers a separate Gemini call.

### Health Analysis (`GET /api/ai/domain?domain=health`)

**What Gemini receives:**
- Weekly averages: sleep, workout, stress, mood, energy, calorie adherence, water intake
- Trends: sleep, health composite
- Behavioral flags: `workoutMoodCorrelation`, `skippedMealPattern`
- Recent qualitative: mood notes

**What the analysis returns:**
- Physiological summary (estimated vs ideal baselines)
- Sleep quality analysis (consistency, not just duration)
- Nutrition synthesis from meal patterns and calorie adherence
- Workout adherence and stress response
- Historical nutrient gaps (inferred from meal patterns and skipped meals)
- Today's curated Indian meal plan addressing detected gaps

### Finance Analysis (`GET /api/ai/domain?domain=finance`)

**What Gemini receives:**
- Weekly averages: savings rate, spending vs budget, impulse rate
- Trends: finance direction
- Behavioral flags: `stressSpendingCorrelation`, `lateNightSpending`
- Pre-computed wealth goals with deficits and timelines

**What the analysis returns:**
- Budget adherence rate
- Spending pattern characterization (consistent saver vs volatile spender)
- Wealth goal feasibility assessment
- Month-end projection (will they hit savings target?)
- Specific intervention if stress-spending pattern detected

### Career Analysis (`GET /api/ai/domain?domain=career`)

**What Gemini receives:**
- Weekly averages: study hours, productivity rating, session count
- Trends: productivity direction
- Qualitative: recent course names, goal focus areas, blockers
- User's career goals

**What the analysis returns:**
- Pareto skill prioritization (20% of skills → 80% of outcome)
- Study block schedule (time-boxed, realistic based on actual logged habits)
- Blocker analysis (recurring `blockerToday` entries surfaced as patterns)
- Career trajectory assessment based on consistency and focus

## Cross-Domain Ripple Effects

The most distinctive aspect of Syntra's AI is that it sees connections between domains that the user may not. These are detected in `buildTwinContext()` and passed to every Gemini prompt.

### Sleep → Career
`behaviorFlags.sleepCareerCorrelation = true` when low-sleep days reliably predict reduced study hours.

**What it means**: Prioritizing sleep isn't just a health decision — it's a career productivity multiplier.

**How it surfaces**: Health analysis warns about sleep deficit. Career analysis flags study drop caused by it. Daily reflection connects both.

### Stress → Finance
`behaviorFlags.stressSpendingCorrelation = true` when high-stress days predict above-average discretionary spending.

**What it means**: Financial decisions are being made under emotional pressure. Stress management is a financial optimization strategy.

**How it surfaces**: Finance analysis flags spending spikes. Health recommendations include stress reduction. Risk alerts call it out explicitly if the pattern is strong.

### Workout → Mood
`behaviorFlags.workoutMoodCorrelation = true` when workout days predict higher mood scores.

**What it means**: Exercise has a measurable positive effect on this user's mood. The Behavioral Twin can quantify it.

**How it surfaces**: Health recommendations prioritize workout consistency. Career recommendations note that post-workout study sessions may be more productive.

### Late Night Spending
`behaviorFlags.lateNightSpending = true` when >30% of finance logs are created after 9pm.

**What it means**: A significant portion of spending decisions happen when cognitive capacity is reduced.

**How it surfaces**: Finance risk alert. Recommendation to avoid purchasing decisions after 9pm.

### Weekend Dropoff
`behaviorFlags.weekendDropoff = true` when weekend scores are consistently lower than weekday scores.

**What it means**: Routine breaks down on unstructured days.

**How it surfaces**: Career recommendations suggest maintaining a light weekend routine. Challenge might be a "Weekend Anchor" task.

## Twin Reasoning

The AI's reasoning is deterministic in input but AI in interpretation. Here's how the chain works:

```
Raw Logs
  ↓ buildTwinContext()
Structured TwinContext
  ↓ Prompt injection
"Given these behavioral averages and flags, analyze the user's trajectory..."
  ↓ Gemini 2.5 Flash (temp: 0.4)
Structured JSON response
  ↓ Zod validation
Typed AI payload → Dashboard
```

**Why temperature 0.4**: High enough to produce natural language, low enough to be consistent. The same context on the same day should produce similar recommendations — determinism matters for trust.

**Why Zod validation on AI output**: Gemini can hallucinate field names or skip required fields. Validation ensures the dashboard never crashes on a malformed AI response. If validation fails, safe defaults are served.

**Why confidence matters**: `ai.confidence` (0–100) gates how assertive recommendations are. At 30% confidence (sparse data), recommendations are gentle suggestions. At 90%+, they're specific directives. This prevents the AI from being overconfident with new users.
